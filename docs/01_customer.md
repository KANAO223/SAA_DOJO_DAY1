## 0. 3行の質について（1つだけ指摘）

2行目に「**週に何本くらい描こうとしていて、1本に何分かかって、どこで手が止まるか**」を足すと、作る画面がぐっと具体的になります。
今回はこちらで数字を仮に置いて進めます（🔮 が付きます）。

## 0-2. 今回どこに絞るか

3行目の「ルーレットで10駅を抽出 → 最短経路を計算 → 地図上に表示」は、**地図描画と経路探索**を含みます。
これは1画面の管理ツールの範囲を超えるため、**今回は「空想路線1本＝1件のデータとして、登録して・探して・どこまで描けたかを進める」部分だけ**に絞ります。

> **絞った理由**: 地図への描画と最短経路の計算は第2回以降の題材で、今回は「自分が作った空想路線を管理する」部分だけを動くツールにするためです。

つまり今回作るのは、**「空想路線ノート」**（考えた路線を1本ずつ登録し、駅を決めた／経路を決めた／描いた、の進み具合を一覧で見る画面）です。

## 1. 今その人はどうやっているか

🔮 ノートや自由帳に、定規とフリーハンドで駅と線を描いている。駅の場所や順番が分からなくなると、スマホやタブレットで路線図を調べ直して、また描き直している。思いついた路線名は頭の中か、紙の隅にメモしている可能性が高い。
   → 確かめ方: 「路線を考えるとき、いまはどこに書いてる？ノート？それともタブレット？」

## 2. かかっている時間 / 費用

🔮 1本の路線図を最後まで描くのに **40〜60分**。そのうち半分近くが「この駅どこだっけ」を調べ直す時間と、線が交差して描き直す時間だと思われる。思いつく頻度は **週2〜3本、月10本前後**。合わせて **月7〜10時間**。費用は自由帳と鉛筆程度でほぼゼロ。
   → 確かめ方: 「1本描くのに、だいたい何分かかってる？ 週に何本くらい考える？」

🔮 それ以上に大きいのは、**描き上がる前に飽きて途中でやめてしまう本数**。考えた路線の半分以上が未完成のまま残っている可能性が高い。
   → 確かめ方: 「途中でやめちゃった路線って、どれくらいある？」

## 3. なぜ今まで誰も解決していないのか

- [ ] データが散っている　[ ] 市場が小さい　[ ] 量が多すぎる
- [ ] 判断が非定型　[x] **n=1すぎる**

🔮 「空想の路線を作る」という遊びは、**一人ひとりルールが違う**（駅の選び方も、線のつなぎ方も、何をもって完成とするかも本人の中にしかない）。誰かのために作っても他の子には合わないと見なされ、商品として作られてこなかった可能性が高い。市場が小さいことも重なっている。
   → 確かめ方: 「路線を作るときの自分ルールってある？ 何ができたら『完成』？」

## 4. このサイトで最初に成立させたいこと（1つだけ）

🔮 **考えた空想路線を、途中でやめずに最後まで1本仕上げられること。**
考えた路線が一覧に残り、「駅を決めた／経路を決めた／描いた」のどこで止まっているかがひと目で分かる状態にする。
   → 確かめ方: 「考えた路線が全部リストで残ってて、続きから描けるとしたら、うれしい？」

## 5. 出口 ── 作る前に確認する3つ

### ① 誰が払うか

🔮 **使う人と払う人が違う。** 使うのは小学生本人、払うのは**保護者（親）**。
   → 確かめ方: 「お子さんの鉄道関係のもの（本・アプリ・グッズ）は、ふだんどれくらい買っていますか？」

🔮 **商習慣はある。** 鉄道系のムック・図鑑・プラレール・知育アプリに、親が数百〜数千円を出す文化は成立していると思われる。ただし**月額課金への抵抗は強い**可能性が高く、買い切りのほうが通りやすい。
   → 確かめ方: 「子ども向けのアプリって、月額と買い切りだとどちらなら払いますか？」

### ② どう届くか

🔮 **下の経路**（紹介・口コミ・既存のつながり）が本命。
具体的には、**鉄道好きの子を持つ親同士のつながり**（同じ習い事・学童・鉄道イベントで顔を合わせる親）、および**子鉄コミュニティ内での又聞き**。
   → 確かめ方: 「お子さんが鉄道の本やアプリを知るきっかけって、たいてい何ですか？ お友達？ YouTube？ 親御さん同士の話？」

🔮 **上の経路（検索・広告・SNS）は今回は取らない。** 「空想 路線図 作る」で検索する小学生はほとんどおらず、広告は親に当てても獲得コストが合わないと思われる。
   → 確かめ方: 「お子さん自身が検索して何かを見つけてくること、ありますか？」

### ③ 受け取れるか（決済・審査・規制）

- **確認したか**: いいえ（今回は決済を作らないため、判定のみ）
- **確認した内容**: 投資・金融／医療・健康／法律相談／暗号資産／ギャンブル／アダルト／情報商材の**いずれにも該当しない**。決済代行の禁止・要審査業種ではない。

🔮 ただし将来お金を取る場合は、**児童向けサービス特有の2点**が効いてくる可能性が高い。
   1. 未成年による課金（保護者の同意なしの決済は取り消され得る）
   2. 子どもの個人情報の扱い（氏名・学校名などを集めない設計にしておくのが安全）
   → 確かめ方: 決済代行（Stripe等）の「子ども向けサービス」の規約を1回だけ読む。顧客に聞く話ではない。

> 今回作るツールは **localStorage にだけ保存**し、名前も連絡先も集めないため、この2点はまだ発生しません。

### 競合には必ず「DIY」を入れる

- **既存の競合**:
  🔮 ノートと鉛筆（いちばん強い競合）／市販の路線図シールブック・鉄道系ムック／大人向けの作図Webツール（小学生には操作が難しいと思われる）／Minecraft や鉄道系ゲームの中で線路を敷く遊び。
     → 確かめ方: 「いま路線を作るのに使ってるアプリやおもちゃって何かある？」

- **DIY競合**（顧客が自分でAIに作らせる）:
  🔮 親が生成AIに「東京23区の駅からランダムに10駅選んで、順番に結んだ路線図を描いて」と頼む。**一度きりなら数分で似たものが出る。**
  ただし、**出てきた1枚をどこにも貯められない**（次に開くと消えている、続きから直せない）。
     → 確かめ方: 「AIに絵や図を描かせたこと、ありますか？ そのあとその画像どうしました？」

- **選ばれる理由**:
  🔮 **時間**。1本40〜60分かかっていた「調べ直し・描き直し」を、考えた路線が全部残っていて続きから進められる状態にすることで実際に減らす。
  加えて 🔮 **埋め込み** の芽がある。「路線を思いついたら、まずここに1行足す」が習慣の中に入れば、ノートの代わりになる。
     → 確かめ方: 「路線を思いついたとき、いちばん最初にやることって何？」

  > ⚠ 機能（ルーレット・最短経路・地図描画）は選ばれる理由に書いていません。数週間で追いつかれるためです。

## 6. やらないこと（3つ）

1. **実際の地図タイルの上に線を描かない。** 経路探索（最短経路の計算）もしない。今回は「どの駅を通すか」をテキストで持つところまで。
2. **他の子と路線を見せ合う機能を作らない。** 共有・投稿・いいね・ランキングは作らない（マッチング／SNSは第3回の題材）。
3. **ログイン・課金・保護者向けの画面を作らない。** データはこの端末のブラウザにだけ置く。

## 🔮 次回までに確かめること

1. **どう届くか（親同士の口コミで本当に伝わるか）** → 誰に聞くか：その子鉄本人と、その保護者 → 質問：「お子さんが鉄道の本やアプリを知るきっかけって、たいてい何ですか？ お友達からですか、YouTubeですか、親御さん同士の話ですか？」
2. **途中でやめている本数（＝解く課題の大きさ）** → 誰に聞くか：子鉄本人 → 質問：「いままで考えた路線って何本くらいある？ そのうち、最後まで描けたのは何本？」
3. **何をもって「完成」とするか（＝自分ルール）** → 誰に聞くか：子鉄本人 → 質問：「路線を作るときの自分ルールってある？ どこまでできたら『これで完成』ってなる？」

このうち ② どう届くか だけは、量では取り返せません。最優先で確かめてください。
